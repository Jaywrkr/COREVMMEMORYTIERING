# TE Web Lab

Base web para construir, por partes, una experiencia interactiva que explique temas complejos de forma simple y digerible.

## Scripts

```bash
npm install
npm run dev
npm run build
```

## Flujo sugerido

1. Crear una rama por seccion o idea.
2. Implementar la experiencia.
3. Validar en local.
4. Abrir PR.
5. Mergear y repetir.
